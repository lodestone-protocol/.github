# Security Policy

## Supported Versions
Only the v1.3.0 final release of Lodestone Protocol is officially supported.

| Version | Supported          |
| ------- | ------------------ |
| v1.3.0  | :white_check_mark: |
| < v1.3  | :x:                |

## Reporting a Vulnerability

**Do NOT create public GitHub issues for security‑related vulnerabilities.**

Please report vulnerabilities privately via the GitHub Security Advisory feature on the corresponding repository:
- Specification issues: https://github.com/lodestone‑protocol/lodestone‑spec/security/advisories
- Reference implementation issues: https://github.com/lodestone‑protocol/lodestone‑md/security/advisories

You will receive an acknowledgement within 7 business days.
We will work with you to validate, triage and resolve the reported issue.
