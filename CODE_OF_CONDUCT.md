# Code of Conduct

This project adheres to an open‑source collaborative code of conduct.
We expect all participants to be respectful, constructive, and considerate towards others.

- Be kind and respectful to all community members.
- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Focus on what is best for the project and community.
- Avoid harassment, offensive or derogatory behaviour.

If you observe violations of this code of conduct, please report via private GitHub advisory channels.
